# Archive and Backup Directory (bkp)

This directory securely archives legacy drafts, superseded project files, and alternative journal submission packages to keep the main repository tree clean, unambiguous, and publication-ready.

## Directory Structure:
1. **`Paper_Phase_I_Legacy/`**:
   - Initial Phase-I research paper drafts created in July 2026 (`main.tex`, `springer_paper.tex`).
   - Completely superseded by the accepted conference paper (`Research Papers/conf paper/`) and the flagship Q1 journal paper (`Research Papers/journal paper/`).

2. **`Elsevier_AIIM/`**:
   - Complete alternative journal submission package formatted for *Elsevier Artificial Intelligence in Medicine (AIIM)* [Q1, Impact Factor: 7.5].
   - Contains Elsevier 5p twocolumn `main.tex`, `main.pdf`, `ref.bib`, `images/`, `Elsevier_AIIM_Cover_Letter.md`, and `Elsevier_AIIM_Submission_Checklist.md`.

3. **`legacy_drafts/`**:
   - Intermediate, unverified, and pre-serialization working drafts (`main_revised.tex`, `main_legacy_unverified.tex`, `main_revised.pdf`) preserved for audit trail reproducibility.
